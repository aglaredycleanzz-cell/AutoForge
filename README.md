# AutoForge

AutoForge is an Android app starter for vehicle part exploration, OEM/part-code notes, exterior customization planning, and maintenance organization.

## Current build

- Native Android app written in Java.
- Arabic-first right-to-left interface.
- Black and red visual identity.
- Minimum Android version: Android 7.0 (API 24).
- Target SDK: API 35.
- GitHub Actions builds a debug APK on pushes to `main` and manual workflow dispatch.

## Build APK

Open **Actions → Build AutoForge Android APK**. After a successful run, download the `AutoForge-Android-APK` artifact.

The current version is a UI foundation; interactive parts diagrams, real OEM lookup, vehicle-specific data, and saved project storage are not implemented yet.
